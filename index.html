Course Overview

What you will learn

SENG 42293 Big Data Analytics builds analytics on top of the Hadoop/Spark infrastructure from SENG 41303 Big Data Infrastructure. You will learn to reason about the characteristics of big data, collect and sample it responsibly, make it trustworthy, and then analyse it with descriptive, predictive and prescriptive methods, survival analysis, text and sentiment analytics, social-network analytics, web analytics and visualisation.

Four capabilities run through the course: understanding big data and its opportunities and challenges; engineering data quality for structured and semi-structured sources; choosing and applying the right analytical method; and operating on multi-node clusters with Spark.

3 Parts · 12 Lectures · Weekly Labs · 1 Semester Project

Assessment: end-of-semester examination (70%), travel-review analytics pipeline project (20%), concepts quiz (10%). Weekly labs are practice for the exam and project and carry no marks.

Assessments

Labs, project & examinations

Weekly Labs · Individual

Hands-on Notebook Labs

Weekly · Jupyter + PySpark (or Databricks Community Edition)

Each lecture has a practical: the sampling notebook, the data-quality pipeline, the word-count activity, and the pipeline lab. Not graded: they are the practice that prepares you for the project and the examination, so attempt every one and compare your results with the solutions discussed in class.

  • Run every cell; explain what each result means
  • Answer the discussion questions in your own words
  • Ask for feedback in class or office hours
Formative · not graded

Semester Project

Travel-Review Analytics Pipeline

Continuous · built up week by week · demonstrated at the end

Teams build an end-to-end analytics pipeline on a travel-review dataset, following the Pipeline Guide and adding a new analytics layer each stage. Use a licensed public dataset or an API whose terms allow reuse.

  • M1 (after L02) — data source and sampling plan
  • M2 (after L04) — ingest, flatten, clean, store as Parquet
  • M3 (after L06) — descriptive dashboard and a first predictive model
  • M4 (after L09) — text and sentiment features
  • M5 (after L12) — full pipeline on a multi-node cluster + demo and report
20% of Final Grade

Mid-Semester Quiz

Concepts Quiz

Mid-semester · covers Part I (Lectures 01 – 04)

Short-answer and multiple-choice questions on big-data characteristics, sampling, data quality and Spark's execution model.

  • Classify examples by the V's; spot sampling bias
  • Choose imputation and outlier strategies for a scenario
  • Explain narrow vs wide transformations
10% of Final Grade

Final Examination

End-of-Semester Examination

Examination Period · Covers all 12 lectures

Tests application and judgement: choosing methods, interpreting outputs, and designing a pipeline for a stated problem, rather than recalling definitions.

  • Part I — collection, sampling, quality, Spark
  • Part II — descriptive, predictive, prescriptive, survival
  • Part III — text, network, web, visualisation
70% of Final Grade

Your Journey

Learning path through this course

Weeks 1–2
Establish foundations. Learn the five V's, then how data is collected and sampled. Run the sampling notebook and check the bias examples against your own project data source.
Weeks 3–4
Make data trustworthy. Work through the cleaning pipeline and the semi-structured data lecture. Do the word-count activity, then run the Pipeline Guide through step 6.
Weeks 5–8
Analyse. Descriptive, predictive and prescriptive analytics, then survival analysis. Extend your project pipeline with a dashboard and a first model.
Weeks 9–11
Specialise. Text and sentiment, social networks, and web analytics. Replace the toy sentiment lexicon in the pipeline with real text features.
Week 12
Synthesise. Visualise and communicate. Run the whole pipeline on a multi-node cluster (Pipeline Guide step 7) and present your project.
Exam Period
Final examination. Practise explaining your pipeline decisions: why this sampling design, this imputation, this storage format.

About This Module

Module Information

SENG 42293 — Big Data Analytics is a 3-credit Level 4 compulsory module delivered by Eng. Dr. Tiroshan Madushanka of the Software Engineering Teaching Unit, University of Kelaniya.

Pre-requisite: SENG 41303 Big Data Infrastructure. You should be comfortable with the Hadoop/Spark ecosystem, distributed storage concepts and basic cluster operations.

Academic integrity: labs, notebooks and project reports are checked for plagiarism. Write explanations in your own words.

Software to install: Python 3.10–3.13, Jupyter, Java 17, PySpark 3.5 (or Databricks Community Edition), and Docker Desktop for the cluster lab.

Contact: Office hours by appointment. Use the University LMS for submissions and announcements.
